### How I work

- **Ownership end to end.** System design through deployment, operations, and incident recovery — not just the part that ships.
- **Design for the failure case first.** Retries, backoff, reconciliation, and state machines belong in the original design, not in the postmortem.
- **Measure before optimizing.** P95s and query plans over intuition.
- **Security as an architectural property.** Isolation and least privilege enforced by structure, not by convention.
- **Leave the codebase teachable.** Clear boundaries, documentation, and review that actually transfers knowledge.
